# Core content schema

All IDs are UUIDs generated by PostgreSQL. All timestamps are UTC
`timestamptz`. Every `position` is a non-negative integer. Mutable authored rows
have `row_version integer not null default 1 check (row_version > 0)`. The API
maps `row_version` to `version`; every `expectedVersion` compares this column.

## Shared types

- `app_role`: `learner`, `editor`, `admin`
- `content_status`: `draft`, `published`, `archived`
- `exercise_type`: `single_choice`, `multiple_choice`, `short_text`,
  `python_code`
- `question_type`: `single_choice`, `multiple_choice`, `short_text`
- `quiz_attempt_status`: `in_progress`, `submitted`, `expired`
- `authored_resource_type`: `module`, `chapter`, `theory_section`, `exercise`,
  `quiz`

## `public.modules`

| Column | Rule |
| --- | --- |
| `id` | primary key |
| `slug` | required, globally unique, lowercase kebab-case |
| `title` | required, trimmed, 1–160 characters |
| `description_markdown` | required, 1–10,000 characters |
| `position` | required, unique among modules, deferrable |
| `status` | default `draft` |
| `row_version` | increment on every mutable update |
| `published_at` | null until first publish |
| `created_by`, `updated_by` | profile FK, `on delete set null` |
| `created_at`, `updated_at` | managed timestamps |

Indexes: unique slug; learner list `(status, position, id)`; actor FKs.

## `public.chapters`

| Column | Rule |
| --- | --- |
| `id` | primary key |
| `module_id` | required module FK, `on delete restrict` |
| `slug` | required, unique within module |
| `title` | required, 1–160 characters |
| `summary_markdown` | required, 1–5,000 characters |
| `position` | unique within module, deferrable |
| `estimated_minutes` | integer from 1 through 1,440 |
| `status`, `row_version`, `published_at` | lifecycle fields |
| audit timestamps/actors | same convention as modules |

Indexes: `(module_id, status, position, id)` and actor FKs.

## `public.theory_sections`

| Column | Rule |
| --- | --- |
| `id` | primary key |
| `chapter_id` | required chapter FK, `on delete restrict` |
| `title` | required, 1–160 characters |
| `body_markdown` | required, 1–100,000 characters |
| `position` | unique within chapter, deferrable |
| `estimated_minutes` | integer from 1 through 1,440 |
| `status`, `row_version`, `published_at` | lifecycle fields |
| audit timestamps/actors | same convention |

Indexes: `(chapter_id, status, position, id)` and actor FKs.

## Common content constraints

- Slug regex is `^[a-z0-9]+(?:-[a-z0-9]+)*$`.
- Stored titles/slugs must equal their trimmed form.
- A `published` row has non-null `published_at`.
- An `archived` row cannot be returned to published; clone it.
- No normal application grant, adapter, RPC, or HTTP route hard-deletes an
  authored root resource (module/chapter/theory section/exercise/quiz) or
  published history. Foreign keys still use `ON DELETE RESTRICT`; any future
  root purge is a separately approved maintenance/privacy migration with
  explicit dependency and history checks. The one narrow exception is
  replacement of unpublished assessment child/key rows described by
  SUP-DATA-002.
- Reordering accepts the complete sibling ID list and updates all positions in
  one transaction using the deferrable unique constraint.
- Draft updates require `expectedVersion`; update matches it and increments
  `row_version`. A mismatch produces a conflict.
