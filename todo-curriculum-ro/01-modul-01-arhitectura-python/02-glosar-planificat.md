# Glosar planificat

Glosarul este sursa unică pentru terminologia modulului. Fiecare intrare finală
va avea termen românesc, termen englezesc, definiție de maximum trei propoziții,
un exemplu Study Tracker și o confuzie frecventă.

## Intrări obligatorii

- arhitectură software;
- design software;
- cerință funcțională;
- atribut de calitate;
- responsabilitate;
- limită arhitecturală;
- cuplare și coeziune;
- dependență și direcția dependenței;
- strat;
- monolit și monolit modular;
- domeniu, entitate, obiect-valoare, invariantă;
- caz de utilizare și serviciu de aplicație;
- DTO și contract;
- inversarea și injectarea dependențelor;
- port, adaptor și arhitectură hexagonală;
- repository;
- rădăcină de compoziție;
- test unitar, fake, mock, test de contract, integrare și arhitectură;
- ADR și compromis;
- MVC, eveniment, microserviciu.
- Python-on-WebAssembly, runtime și profil runtime;
- pachet `python_code`, test public și test privat;
- rezultat local provizoriu și verificare autoritativă.
