# Următorul task

Singurul task eligibil este:

> **CURR-PLAN-001 — Acceptarea sau modificarea planului curricular.**

În acest task utilizatorul confirmă sau modifică:

- publicul și prerechizitele;
- cele opt capitole;
- aplicația Study Tracker;
- politica quizurilor;
- separarea cheilor/răspunsurilor;
- limitele curriculare pentru pachetele multi-fișier `python_code`.

Decizia utilizatorului ca verificarea codului să folosească Python-on-
WebAssembly este deja obligatorie: rularea server-side este autoritativă, iar
un viitor preview din browser este numai provizoriu. CURR-PLAN-001 nu poate
înlocui această cerință cu CPython nativ și nu autorizează implementarea unui
frontend.

Nu redacta lecții, exemple, exerciții, quizuri sau soluții în CURR-PLAN-001.
