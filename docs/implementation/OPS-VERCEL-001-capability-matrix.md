Scope: current public official Vercel documentation only; no account or hosted
state was accessed.

named plane only; it is not a creation authorization. **Gap** means the
documentation does not prove a Coditza requirement. **Unselected** means no
provider, service, tier, region, account, or credential has been chosen.

## Cross-plane constraints

- Vercel is retained as the public Fastify API destination. No alternative public
  host is selected or implied.
- A public function does not gain a general Docker socket, a private controller,
  a migration credential, or an authoritative code-execution role.
- Development, Preview, and Production environment variables are separate in
  Vercel's model. A future preview promotion rebuilds with Production values,
  so Preview evidence cannot silently stand in for a Production artifact.
  [Promoting Deployments](https://vercel.com/docs/deployments/promoting-a-deployment)
- Sensitive environment-variable masking is a dashboard/readback control, not
  permission to log secrets or put them in browser/public code. No variable was
  added or inspected in this task.
- Exact Vercel plan, region, egress mechanism, cost, ownership, private-host
  vendor, and launcher remain user-approval decisions. This matrix makes no
  billing or external-state change.
